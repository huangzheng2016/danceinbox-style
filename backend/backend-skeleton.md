# Backend Skeleton Reference

Concrete templates for `main.go`, `container/`, `biz/mw/mw.go`, config schema, and embed wiring. Read this when bootstrapping a new project or wiring a new top-level dependency.

## Dependencies (resolve at scaffold, upgrade deliberately)

Do NOT paste version numbers into `go.mod` by hand. Seed the initial module set versionless and let the toolchain resolve a compatible release of each. After scaffolding, commit `go.mod` / `go.sum` and upgrade modules deliberately, one change at a time with generation, build, and tests. Do not run blanket `go get -u` on an established project.

```bash
go mod init <MODULE_NAME>

go get \
    github.com/cloudwego/hertz \
    github.com/hertz-contrib/cors \
    github.com/hertz-contrib/etag \
    github.com/hertz-contrib/gzip \
    github.com/hertz-contrib/i18n \
    github.com/hertz-contrib/secure \
    github.com/spf13/viper \
    gorm.io/gorm \
    gorm.io/driver/mysql \
    gorm.io/gen \
    github.com/redis/go-redis/v9 \
    github.com/go-redsync/redsync/v4 \
    github.com/golang-jwt/jwt/v5 \
    github.com/google/wire \
    github.com/google/uuid \
    golang.org/x/crypto \
    golang.org/x/text \
    golang.org/x/time

go mod tidy
```

The initial bare `go get <mod>` writes resolved versions into `go.mod`/`go.sum` - those are the recorded pins. Reproducibility comes from the committed module files and deliberate upgrades, not from a hand-written require block or an always-latest rule.

Note: `go mod tidy` on an EMPTY module (before any source file imports these) will prune the whole block back out. Run tidy after source exists, not before. And once `hz` codegen has run (see `idl-workflow.md`), the first tidy that follows MUST be paired with `go get github.com/apache/thrift@v0.13.0` — see "Known cliffs" below.

Profile adjustments:

- **Lightweight profile**: skip `gorm.io/driver/mysql`, `go-redis`, `redsync`; add `github.com/glebarez/sqlite` instead.
- **Casbin escalation only**: `go get github.com/casbin/casbin/v2 github.com/casbin/gorm-adapter/v3`.
- Add domain libs (`hertz-contrib/http2`, `gorm.io/datatypes`, ...) only when a feature actually needs them. Do NOT add preemptively.

### Known cliffs — places where "latest" genuinely breaks

| Module | Pin | Why |
|--------|-----|-----|
| `github.com/apache/thrift` | `v0.13.0` — MANDATORY right after the first `go mod tidy` that follows `hz` codegen; never `go get -u` it afterwards | thriftgo is a standalone binary, so nothing in the module graph holds thrift at the version its generated code compiles against; tidy floats it to latest and the build breaks. |
| `gorm.io/plugin/dbresolver` (transitive via `gorm.io/gen`) | `v1.6.2` — sanctioned pin | gen's required floor does not compile against gorm latest (`gorm.Stmt` removed). Re-check on the next gen bump. |
| `golang.org/x/tools` (transitive via `gorm.io/gen`) | `latest` — sanctioned exception to the no-blanket-latest rule, ONLY if `go run ./cmd/generate` fails with a `tokeninternal` compile error | gen's older pinned x/tools (v0.21.x) does not compile on recent Go. MVS usually lifts past it; bump only if you actually hit the error. Re-check on the next gen bump. |

- Toolchain baseline is **Go 1.26** (Dockerfile `golang:1.26-bookworm`, CI `go-version: '1.26'`). `x/crypto` latest needs no pin at this baseline — its `go 1.26` directive matches the toolchain. Install the codegen binaries (hz / wire / thriftgo) with the same Go 1.26 toolchain: a binary built by an older Go refuses to load packages whose `go.mod` requires 1.26.
- **No blanket `go get -u ./...`**, ever. Bump per-module with a reason, then `go build ./...` + `go test ./...`.
- If a latest release genuinely misbehaves, fall back to this verified-compatible set (known to work together in production): `hertz v0.10.x`, `cors v0.1.0`, `etag v0.1.0`, `gzip v0.0.3`, `i18n v0.1.0`, `secure v0.0.0-20221010065415-c2ee6f6bd0ca`, `go-redis/v9 v9.17.1`, `redsync/v4 v4.14.1`, `glebarez/sqlite v1.11.0`, `uuid v1.6.0`, `x/time v0.14.0`, `x/crypto v0.47.0`.

## main.go Boot Sequence

```go
package main

import (
    "context"
    "crypto/tls"
    "flag"
    "fmt"
    "log"
    "os"
    "time"

    "<MODULE_NAME>/biz/dal/mysql"
    "<MODULE_NAME>/biz/handler"
    "<MODULE_NAME>/biz/mw"
    "<MODULE_NAME>/config"
    "<MODULE_NAME>/container"
    "<MODULE_NAME>/localize"

    "github.com/cloudwego/hertz/pkg/app"
    "github.com/cloudwego/hertz/pkg/app/server"
    "github.com/cloudwego/hertz/pkg/common/json"
    "github.com/hertz-contrib/cors"
    "github.com/hertz-contrib/etag"
    "github.com/hertz-contrib/gzip"
    "github.com/hertz-contrib/i18n"
    "github.com/hertz-contrib/secure"
    "golang.org/x/text/language"
)

var version = "dev"       // overridden by build.sh: -ldflags "-X main.version=$VERSION"
var releaseMode = "false" // overridden by release builds: -ldflags "-X main.releaseMode=true"

const maxServerRequestBodySize = 4 << 30 // 4GB

// applyBuildRuntimeMode is the hook for build-flavor behavior (e.g. release-only
// logging tweaks). Keep it a no-op until a project actually needs one - it exists
// so the -ldflags flag always has a symbol to land on.
func applyBuildRuntimeMode() {}

func main() {
    applyBuildRuntimeMode()

    if loc, err := time.LoadLocation("Asia/Shanghai"); err == nil {
        time.Local = loc
    }

    cfg := flag.String("c", "local", "config name (local|test|pre|prod)")
    flag.Parse()
    if *cfg == "" {
        log.Fatal("config name required")
    }
    if err := config.LoadConfig(*cfg); err != nil {
        log.Fatalf("load config: %v", err)
    }

    mysql.InitMysql()
    container.InitDefault()
    mw.InitMw()

    var h *server.Hertz
    addr := fmt.Sprintf("%s:%d", config.GetConfigStr("server.host"), config.GetConfigInt("server.port"))
    // server.tls = the app itself serves TLS; cookie Secure is jwt.cookie_secure (see "config Schema").
    if config.GetConfigBool("server.tls") {
        h = serveTLS(addr)
    } else {
        h = server.Default(
            server.WithHostPorts(addr),
            server.WithMaxRequestBodySize(maxServerRequestBodySize),
            server.WithStreamBody(true),
        )
    }
    h.NoHijackConnPool = true

    h.Use(i18n.Localize(
        i18n.WithBundle(&i18n.BundleCfg{
            AcceptLanguage:   []language.Tag{language.Chinese, language.English},
            DefaultLanguage:  language.Chinese,
            FormatBundleFile: "json",
            UnmarshalFunc:    json.Unmarshal,
            Loader:           i18n.LoaderFunc(localize.GetLocalizeFiles),
        }),
        i18n.WithGetLangHandle(func(c context.Context, ctx *app.RequestContext, defaultLang string) string {
            // Query param wins; otherwise fall back to the frontend's LOCALE
            // cookie (see frontend/skeleton.md — vue-i18n switches via LOCALE).
            if l := string(ctx.Query("lang")); l != "" {
                return l
            }
            if l := string(ctx.Cookie("LOCALE")); l != "" {
                return l
            }
            return defaultLang
        }),
    ))
    os.MkdirAll(config.GetConfigStr("server.upload_path"), 0o755)
    h.Use(mw.RequestIDMw())
    h.Use(cors.New(cors.Config{
        AllowOrigins:     config.GetConfigStrSliceOptional("server.allowed_origins"),
        AllowMethods:     []string{"GET", "POST", "PUT", "DELETE", "OPTIONS"},
        AllowHeaders:     []string{"Origin", "Content-Type", "Authorization"},
        ExposeHeaders:    []string{"Content-Length", "Content-Type", "X-Token-Refresh-Needed"},
        AllowCredentials: true,
    }))
    h.Use(gzip.Gzip(gzip.DefaultCompression))
    h.Use(etag.New())
    h.Use(secure.New(
        // secure's default config has SSLRedirect: true — on plain HTTP (local dev,
        // and in compose where TLS terminates at Caddy) every request 301s forever.
        secure.WithSSLRedirect(false),
        secure.WithContentSecurityPolicy(
            "default-src 'self'; style-src 'self' 'unsafe-inline'; script-src 'self' 'unsafe-inline'; connect-src 'self'; img-src 'self' blob: data:;",
        ),
    ))
    handler.BuildVersion = version // stamp /healthz with the build version
    register(h) // calls biz/router.GeneratedRegister(h) + customizedRegister(h)

    h.OnShutdown = append(h.OnShutdown, func(ctx context.Context) {
        time.Sleep(2 * time.Second) // drain in-flight requests
    })
    h.Spin()
}

func serveTLS(addr string) *server.Hertz {
    cert, err := tls.LoadX509KeyPair(
        config.GetConfigStr("server.cert"),
        config.GetConfigStr("server.key"),
    )
    if err != nil {
        log.Fatalf("tls: %v", err)
    }
    return server.Default(
        server.WithHostPorts(addr),
        server.WithMaxRequestBodySize(maxServerRequestBodySize),
        server.WithStreamBody(true),
        server.WithTLS(&tls.Config{Certificates: []tls.Certificate{cert}, MinVersion: tls.VersionTLS12}),
    )
}
```

**Do not reorder.** Each step depends on the previous one having completed (e.g. `mw.InitMw` reads config; `container.InitDefault` reads mysql).

## `router.go` + `router_gen.go` Split

```go

package main

    bizrouter "<MODULE_NAME>/biz/router"

```

```go
// router.go - hand-written. customizedRegister for non-IDL routes.
package main

import (
    "context"
    "strings"

    "<MODULE_NAME>/biz/consts"
    "<MODULE_NAME>/biz/handler"

    "github.com/cloudwego/hertz/pkg/app"
    "github.com/cloudwego/hertz/pkg/app/server"
)

func customizedRegister(r *server.Hertz) {
    r.GET("/ping", handler.Ping)     // legacy lightweight alias
    r.GET("/livez", handler.Livez)   // liveness: process is up
    r.GET("/healthz", handler.Healthz) // readiness: dependency probes (mysql, redis)

    // Static assets + SPA fallback. In Hertz, NoRoute only fires when NO
    // registered route matched, so registration order vs. the static routes
    // below does not matter — but they must exist as real routes, otherwise
    // asset requests would fall through to NoRoute and get HTML. The admin
    // bundle builds with base '/admin/', so admin.html references
    // /admin/assets/* — without that second route the admin SPA white-screens
    // in embed mode. The fallback is required only for history-mode routing;
    // under the default hash mode the fragment never reaches the server, so
    // it is harmless but not necessary there.
    httpFS := getFrontendHTTPFS()
    r.GET("/assets/*path", serveStaticFile(httpFS))
    r.GET("/admin/assets/*path", serveStaticFile(httpFS))
    r.GET("/favicon.ico", serveStaticFile(httpFS))
    r.NoRoute(func(ctx context.Context, c *app.RequestContext) {
        path := string(c.Path())
        if isAPIPath(path) {
            c.JSON(404, map[string]any{"code": consts.ErrNotFound, "msg": "Not Found"})
            return
        }
        // Admin SPA fallback: /admin/* refreshes must get the admin entry,
        // which Vite emits as dist/admin/admin.html (NOT index.html).
        if path == "/admin" || strings.HasPrefix(path, "/admin/") {
            serveSPAFile(httpFS, "admin/admin.html", ctx, c)
            return
        }
        serveSPAFile(httpFS, "index.html", ctx, c)
    })

    // SSE / WebSocket / other streaming routes go here, with their own middleware
    // chain. Streaming routes must skip gzip/etag wrapping or the stream stalls.
}

func isAPIPath(p string) bool {
    // Exact segment match: /api and /api/* (plus the /papi equivalents).
    // A bare HasPrefix("/api") would misclassify history routes like
    // /apiary as API and rob them of the SPA fallback.
    return p == "/api" || strings.HasPrefix(p, "/api/") ||
        p == "/papi" || strings.HasPrefix(p, "/papi/")
}
```

The `serveStaticFile` / `serveSPAFile` / `getFrontendHTTPFS` helpers come from `frontend_embed.go` (next section).

SPA fallback scope (when it is optional vs required): see SKILL.md "Routing Mode Decision"; the `NoRoute` comment above has the short version.

Health endpoint naming: there is no `/health` — do not re-add one (see SKILL.md / idl-workflow.md).

## biz/handler/ping.go + health.go

The three health endpoints `router.go` registers live in the ROOT `biz/handler` package (hz owns only the `biz/handler/api` / `biz/handler/papi` subpackages — these two files are hand-written and never touched by codegen).

`ping.go`:

```go
package handler

import (
    "context"

    "github.com/cloudwego/hertz/pkg/app"
)

// Ping is the legacy lightweight alias for Livez.
func Ping(ctx context.Context, c *app.RequestContext) {
    c.JSON(200, map[string]any{"status": "ok"})
}

// Livez is liveness: the process is up. No dependency checks — a dead
// dependency must not get the pod restarted.
func Livez(ctx context.Context, c *app.RequestContext) {
    c.JSON(200, map[string]any{"status": "ok"})
}
```

`health.go`:

```go
package handler

import (
    "context"
    "time"

    "<MODULE_NAME>/biz/dal/mysql"
    "<MODULE_NAME>/container"

    "github.com/cloudwego/hertz/pkg/app"
)

// BuildVersion is stamped from main.version at boot (main.go assigns it
// before register()). It rides in the /healthz body so a deploy can be
// verified from the readiness endpoint alone.
var BuildVersion = "dev"

// Healthz is readiness: probe every hard dependency and report per-dependency
// status plus the build version. 200 only when ALL dependencies answer; 503
// with the failing ones named otherwise.
func Healthz(ctx context.Context, c *app.RequestContext) {
    deps := map[string]string{}

    // The probe goes through the DAL's own Ping constructor — the raw handle
    // never crosses the DAL boundary, not even for health checks.
    if err := mysql.Ping(ctx); err != nil {
        deps["mysql"] = "down: " + err.Error()
    } else {
        deps["mysql"] = "up"
    }

    // IRedis has no Ping on either profile; a 1s Set is the cheapest probe
    // that surfaces errors through the interface and works for the
    // lightweight LocalRedis swap too.
    if err := container.Default.RedisService.Set(ctx, "healthz:probe", "1", time.Second); err != nil {
        deps["redis"] = "down: " + err.Error()
    } else {
        deps["redis"] = "up"
    }

    status, code := "ok", 200
    for _, v := range deps {
        if v != "up" {
            status, code = "degraded", 503
            break
        }
    }
    c.JSON(code, map[string]any{"status": status, "version": BuildVersion, "deps": deps})
}
```

## frontend_embed.go

**Default**: plain `//go:embed`, no runtime extraction.

```go
package main

import (
    "context"
    "embed"
    "io"
    "io/fs"
    "net/http"
    "strings"

    "github.com/cloudwego/hertz/pkg/app"
    "github.com/cloudwego/hertz/pkg/common/adaptor"
)

//go:embed all:frontend/dist
var frontendDist embed.FS

func getFrontendHTTPFS() http.FileSystem {
    sub, err := fs.Sub(frontendDist, "frontend/dist")
    if err != nil {
        panic(err)
    }
    return http.FS(sub)
}

// serveStaticFile serves embedded files through the net/http file server,
// bridged to Hertz via adaptor.HertzHandler. Vite emits hash-named bundles
// under /assets/ (and /admin/assets/ for the admin bundle), so those
// responses get an immutable year-long cache header; everything else stays
// at the browser default (revalidate).
func serveStaticFile(fsys http.FileSystem) app.HandlerFunc {
    fileServer := adaptor.HertzHandler(http.FileServer(fsys))
    return func(ctx context.Context, c *app.RequestContext) {
        p := string(c.Path())
        if strings.HasPrefix(p, "/assets/") || strings.HasPrefix(p, "/admin/assets/") {
            c.Header("Cache-Control", "public, max-age=31536000, immutable")
        }
        fileServer(ctx, c)
    }
}

// serveSPAFile writes one named entry file (the SPA's HTML shell) to the
// response. Always no-cache: the HTML references hash-named assets, so it
// must be revalidated on every load or a fresh deploy would never take effect.
func serveSPAFile(fsys http.FileSystem, name string, _ context.Context, c *app.RequestContext) {
    f, err := fsys.Open(name)
    if err != nil {
        c.Data(404, "text/plain; charset=utf-8", []byte("SPA entry not found: "+name))
        return
    }
    defer f.Close()
    data, err := io.ReadAll(f)
    if err != nil {
        c.Data(500, "text/plain; charset=utf-8", []byte("read SPA entry: "+err.Error()))
        return
    }
    c.Header("Cache-Control", "no-cache")
    c.Data(200, "text/html; charset=utf-8", data)
}
```

The admin bundle (if you build a separate one to `frontend/dist/admin/`) is served by the `/admin/*` branch of the `NoRoute` fallback in `router.go`, which sends the embedded `admin/admin.html`. You do not need a second `//go:embed` directive.

**When to switch to compressed embed**: if `du -sh frontend/dist/` is larger than ~50 MB unpacked, the Go linker starts to slow noticeably and the final binary balloons. At that point migrate to `embed-strategy.md` (zstd archive + runtime extract to user cache dir, content-addressed by SHA256). Until you hit that threshold, plain embed wins on simplicity (no `cmd/embedcompress`, no cache dir, no SHA marker).

## container/container.go

```go
package container

import (
    redis "<MODULE_NAME>/biz/extension/redis"
    user "<MODULE_NAME>/biz/service/user"
)

var Default *Container

func InitDefault() {
    Default = InitContainer()
}

type Container struct {
    RedisService redis.IRedis
    UserService  user.Service
}

func NewContainer(
    redisService redis.IRedis,
    userService user.Service,
) *Container {
    return &Container{
        RedisService: redisService,
        UserService:  userService,
    }
}
```

After adding a new service:
1. Add the provider func to the `wire.Build(...)` list in `wire.go`.
2. Add the field to the `Container` struct.
3. Add the parameter to `NewContainer`.
4. Run `go generate ./container` (the `go:generate` directive in `wire.go` uses the module-pinned Wire version).

If you forget step 4, `wire_gen.go` still works for the OLD set and compilation passes but the new field is `nil`. Read `wire_gen.go` after every regeneration to confirm.

## biz/service/<feature>/service.go Pattern

```go
package user

import (
    "context"
    "errors"
    "strings"

    "<MODULE_NAME>/biz/dal/mysql"
    "<MODULE_NAME>/biz/dal/mysql/model"
    "<MODULE_NAME>/biz/dal/mysql/query"

    "golang.org/x/crypto/bcrypt"
    "gorm.io/gorm"
)

// ErrBadCredentials covers BOTH "no such user" and "wrong password" — never
// distinguish them at the API boundary (user enumeration).
var ErrBadCredentials = errors.New("bad credentials")

// ErrNotFound is the package sentinel for a missing row. The service owns the
// gorm.ErrRecordNotFound translation (data-conventions.md "Reads") — handlers
// and tests assert this sentinel, never the gorm error.
var ErrNotFound = errors.New("not found")

type Service interface {
    GetByID(ctx context.Context, id int64) (*model.User, error)
    Login(ctx context.Context, identifier, password string) (*model.User, error)
}

type serviceImpl struct {
    q *query.Query
}

func NewService() Service {
    return &serviceImpl{q: mysql.GetDBQuery()}
}

func (s *serviceImpl) GetByID(ctx context.Context, id int64) (*model.User, error) {
    u := s.q.User
    user, err := u.WithContext(ctx).Where(u.ID.Eq(id)).First()
    if errors.Is(err, gorm.ErrRecordNotFound) {
        return nil, ErrNotFound
    }
    return user, err
}

// Login accepts username OR email as the identifier and verifies the password
// against the stored bcrypt hash (model.User.PasswordHash).
func (s *serviceImpl) Login(ctx context.Context, identifier, password string) (*model.User, error) {
    u := s.q.User
    cond := u.Username.Eq(identifier)
    if strings.Contains(identifier, "@") {
        cond = u.Email.Eq(identifier)
    }
    user, err := u.WithContext(ctx).Where(cond).First()
    if err != nil {
        return nil, ErrBadCredentials
    }
    if err := bcrypt.CompareHashAndPassword([]byte(user.PasswordHash), []byte(password)); err != nil {
        return nil, ErrBadCredentials
    }
    return user, nil
}
```

Rules:
- Interface in `service.go`, struct + methods in same file or `service_impl.go`.
- `NewService()` is the Wire provider. Keep it pure — no IO at construction. `mysql.GetDBQuery()` is safe here because `container.InitDefault()` runs after `mysql.InitMysql()`.
- Service consumes `query.Query` and speaks `model.*` (DAL models). Handlers consume the service and speak thrift models. Query-method conventions: `data-conventions.md`.

```go
package mw

import (
    "context"
    "sync"

    "github.com/cloudwego/hertz/pkg/app"
    "golang.org/x/time/rate"
)

var (
    rateMu      sync.Mutex
    rateBuckets = map[string]*rate.Limiter{}
)

// RateLimitMw allows 20 r/s with burst 40 per client IP. Tune per project.
func RateLimitMw() app.HandlerFunc {
    return func(ctx context.Context, c *app.RequestContext) {
        ip := c.ClientIP()
        rateMu.Lock()
        l, ok := rateBuckets[ip]
        if !ok {
            l = rate.NewLimiter(rate.Limit(20), 40)
            rateBuckets[ip] = l
        }
        rateMu.Unlock()
        if !l.Allow() {
            c.AbortWithStatus(429)
            return
        }
        c.Next(ctx)
    }
}
```

The `rateBuckets` map never evicts — one small entry per distinct client IP, forever. Acceptable for internal or short-lived deploys; a long-running public service should add lazy eviction (a `lastSeen` sweep or a TTL cache) or move to the Redis-backed limiter above.

`server.tls` and `jwt.cookie_secure` are deliberately SEPARATE knobs:

- `server.tls: true` means the APP ITSELF serves TLS (`serveTLS` in main.go loads `server.cert`/`server.key`). It says nothing about cookies.

Migration rules — what may and may not ride on `autoMigrate`:

- Boot-time `AutoMigrate` is acceptable for the SIMPLE, EARLY phase only: additive changes — new tables, new nullable columns, new indexes. It never drops columns and never rewrites data, and that is exactly why it is safe there.
- Destructive or data-changing work must NOT ride on `AutoMigrate`: dropping/renaming a column, changing a column type, adding `NOT NULL` to an existing table, backfilling values, moving data between tables. These go in explicit, versioned migration steps (a `schema_migrations` table + a `cmd/migrate` one-shot, or an external tool), reviewed like code.
- Every explicit migration step is IDEMPOTENT (guard with `IF NOT EXISTS` / check-then-act) and safe to run twice; large backfills run in batches. Staged rollout for breaking schema changes: expand (add new column) → backfill → switch reads/writes → contract (drop old column) — never all four in one deploy.
- A migration that finds data violating its assumptions FAILS FAST. It does not force-migrate, truncate, or silently "clean" dirty data - report and stop, let a human decide.
- Dialect-specific migration steps guard on the dialect and no-op on the others, so the lightweight/test dialect keeps booting.
- Rollback rule: a migration must be safe while the PREVIOUS release's code is still serving traffic (expand-only per release; contract in a follow-up). A pure-code release rolls back freely. A release that carried migrations is fix-forward, or a restore from the backup taken before that release - never roll code back across a destructive migration.

`model/prefix.go` — table prefix helper used by every model's `TableName()`:

```go

        return name
```

Hand-written model example (`model/user.go`). This is the ONLY model directory you author — structs here are the schema source, consumed by `cmd/generate` and `autoMigrate`:

```go
package model

const TableNameUser = "user"

type User struct {
    ID           int64  `gorm:"column:id;primaryKey;autoIncrement" json:"id"`
    Username     string `gorm:"column:username;type:varchar(128);not null;uniqueIndex" json:"username"`
    Email        string `gorm:"column:email;type:varchar(255);not null;uniqueIndex" json:"email"` // IDL UserInfo.email is required; Login accepts it as identifier
    Avatar       string `gorm:"column:avatar;type:varchar(512);not null;default:''" json:"avatar"`
    PasswordHash string `gorm:"column:password_hash;type:varchar(128);not null;default:''" json:"-"` // bcrypt hash (auth-jwt-casbin.md); json:"-" so it can never leak into a response
    Role         string `gorm:"column:role;type:varchar(32);not null;default:USER" json:"role"`      // USER | MODERATOR | ADMIN
    Active       int32  `gorm:"column:active;type:tinyint;not null;default:1" json:"active"`         // 1 active, 0 disabled - checked by isJwtUserActive
}

func (*User) TableName() string { return GetTableName(TableNameUser) }
```

The primary key tag is deliberately TYPE-LESS (`primaryKey;autoIncrement`, no explicit `type:`), so GORM maps `int64` to `bigint auto_increment` on MySQL and to `INTEGER PRIMARY KEY` on SQLite — the only form SQLite auto-increments. An explicit `type:bigint unsigned` compiles on MySQL but silently yields a non-autoincrementing column on SQLite, leaving `ID` at zero after `Create` and breaking everything downstream. Explicit `type:` on NON-key columns (varchar, tinyint, ...) is fine.

Adding fields to a model struct needs NO change in `model.MigratedModels()` — generation and migration both reference the struct as a whole, so new columns are picked up on the next `go run ./cmd/generate` and boot. This rides on AutoMigrate safely because the skeleton defines the schema for a NEW project (table created fresh at first boot); adding a `NOT NULL`-without-default column like `email` to an ALREADY-POPULATED table later would fall under the destructive-change rules above, not under AutoMigrate.

## biz/extension/redis (full profile)

The Wire provider and the seam every call site uses. Full-profile `IRedis` is a SUPERSET of the lightweight one (`lite-profile.md`) — it adds `GetClient` (Redsync needs it) and `SubscribeChannel`/`Publish` (Casbin policy notify needs them). Semantics are the contract both profiles share (`LocalRedis` in `lite-profile.md` preserves them): values are JSON round-tripped, TTLs honored, lock `Unlock` cannot release someone else's lock.

Lock contract: lock-acquisition failures are RETURNED, never swallowed. `LockWithKey` yields `(Locker, error)` — a nil locker with a non-nil error means the lock was NOT acquired (already held, or Redis down). Callers must decide: retry, skip, or fail the operation. Never proceed as if the lock were held after an error, and never log-and-continue past it.

Pub/sub contract: long-lived consumers go through `SubscribeChannel`, NOT a bare `Subscribe(...).Channel()` loop copied into business code. `SubscribeChannel` blocks until `ctx` is cancelled (run it in a goroutine), resubscribes automatically when the connection drops (with backoff), and reports every receive/resubscribe failure through `onError` so the caller can log or alert. Messages published during an outage are LOST — pub/sub has no replay — so consumers must tolerate missed notifications (e.g. Casbin policy reload just resyncs on the next message or restart).

`interface.go`:

```go
package redis

import (
    "context"
    "errors"
    "time"

    goredis "github.com/redis/go-redis/v9"
)

var ErrCacheMiss = errors.New("cache miss")

type Locker interface {
    Lock() error
    TryLock() error
    Unlock() (bool, error)
}

type IRedis interface {
    Set(ctx context.Context, key string, value interface{}, expiration time.Duration) error
    Get(ctx context.Context, key string, value interface{}) error
    Delete(ctx context.Context, key string) error
    Exists(ctx context.Context, key string) bool
    Mutex(ctx context.Context, key string, ttl time.Duration) Locker
    TryLockWithKey(ctx context.Context, key string, ttl time.Duration) (Locker, error)
    LockWithKey(ctx context.Context, key string, ttl time.Duration) (Locker, error)
    GetClient() *goredis.Client
    SubscribeChannel(ctx context.Context, channel string, onMessage func(payload string), onError func(err error))
```

`redis.go`:

```go
package redis

import (
    "context"
    "encoding/json"
    "errors"
    "time"

    "<MODULE_NAME>/config"

    "github.com/go-redsync/redsync/v4"
    goredis_pool "github.com/go-redsync/redsync/v4/redis/goredis/v9"
    goredislib "github.com/redis/go-redis/v9"
)

type goRedis struct {
    c  *goredislib.Client
    rs *redsync.Redsync
}

// NewRedis is the Wire provider.
func NewRedis() IRedis {
    c := goredislib.NewClient(&goredislib.Options{
        Addr:     config.GetConfigStr("redis.addr"),
        Password: config.GetConfigStrOptional("redis.password"),
        DB:       config.GetConfigInt("redis.db"),
    })
    if err := c.Ping(context.Background()).Err(); err != nil {
        panic("[redis] ping failed: " + err.Error())
    }
    return &goRedis{c: c, rs: redsync.New(goredis_pool.NewPool(c))}
}

func (r *goRedis) Set(ctx context.Context, key string, value interface{}, expiration time.Duration) error {
    data, err := json.Marshal(value)
    if err != nil {
        return err
    }
    return r.c.Set(ctx, key, data, expiration).Err()
}

func (r *goRedis) Get(ctx context.Context, key string, value interface{}) error {
    data, err := r.c.Get(ctx, key).Bytes()
    if errors.Is(err, goredislib.Nil) {
        return ErrCacheMiss
    }
    if err != nil {
        return err
    }
    return json.Unmarshal(data, value)
}

func (r *goRedis) Delete(ctx context.Context, key string) error {
    return r.c.Del(ctx, key).Err()
}

func (r *goRedis) Exists(ctx context.Context, key string) bool {
    n, err := r.c.Exists(ctx, key).Result()
    return err == nil && n > 0
}

type redsyncLocker struct{ m *redsync.Mutex }

func (l *redsyncLocker) Lock() error              { return l.m.Lock() }
func (l *redsyncLocker) TryLock() error           { return l.m.TryLock() }
func (l *redsyncLocker) Unlock() (bool, error)    { return l.m.Unlock() }

func (r *goRedis) mutex(key string, ttl time.Duration) *redsync.Mutex {
    return r.rs.NewMutex("lock:"+key, redsync.WithExpiry(ttl))
}

func (r *goRedis) Mutex(ctx context.Context, key string, ttl time.Duration) Locker {
    return &redsyncLocker{m: r.mutex(key, ttl)}
}

func (r *goRedis) TryLockWithKey(ctx context.Context, key string, ttl time.Duration) (Locker, error) {
    l := &redsyncLocker{m: r.mutex(key, ttl)}
    if err := l.TryLock(); err != nil {
        return nil, err
    }
    return l, nil
}

func (r *goRedis) LockWithKey(ctx context.Context, key string, ttl time.Duration) (Locker, error) {
    l := &redsyncLocker{m: r.mutex(key, ttl)}
    if err := l.Lock(); err != nil {
        return nil, err
    }
    return l, nil
}

func (r *goRedis) GetClient() *goredislib.Client { return r.c }

// SubscribeChannel blocks until ctx is cancelled; run it in a goroutine.
// When the connection drops the subscription channel closes — resubscribe
// with backoff instead of letting the consumer die silently.
func (r *goRedis) SubscribeChannel(ctx context.Context, channel string, onMessage func(payload string), onError func(err error)) {
    backoff := time.Second
    for {
        sub := r.c.Subscribe(ctx, channel)
        for msg := range sub.Channel() {
            onMessage(msg.Payload)
        }
        _ = sub.Close()
        if ctx.Err() != nil {
            return // shutdown: caller cancelled, exit quietly
        }
        if onError != nil {
            onError(errors.New("pubsub channel closed; resubscribing"))
        }
        select {
        case <-ctx.Done():
            return
        case <-time.After(backoff):
        }
        if backoff < 30*time.Second {
            backoff *= 2
        }
    }
}

func (r *goRedis) Publish(ctx context.Context, channel string, payload string) error {
    return r.c.Publish(ctx, channel, payload).Err()
}
```

Nothing outside this package imports `goredis` — that is what keeps the lightweight `LocalRedis` a legal swap.

```go
    ErrForbidden    = 1003
    ErrNotFound     = 1004
    ErrConflict     = 1005 // used by idl-workflow.md / data-conventions.md state transitions
)
```

`JwtTypeAccess` / `JwtTypeRefresh` are NOT defined here — they live in `consts/auth.go` (see `auth-jwt-casbin.md`), so each symbol has exactly one definition in `package consts`. Domain failures like `ErrInsufficientBalance` are per-service sentinel errors (`var ErrX = errors.New(...)` in the owning service package, see `data-conventions.md`), not numeric codes — they never enter `consts`.

## utils/utils.go

Helpers referenced by the handler and query patterns. Keep this file small — one-off helpers do not belong here:

```go
package utils

import "strings"

func Ptr[T any](v T) *T { return &v }

// LikeQueryStr escapes LIKE metacharacters and wraps the term for a contains-match.
// See data-conventions.md — raw user input never goes into .Like directly.
func LikeQueryStr(s string) string {
    s = strings.ReplaceAll(s, `\`, `\\`)
    s = strings.ReplaceAll(s, `%`, `\%`)
    s = strings.ReplaceAll(s, `_`, `\_`)
    return "%" + s + "%"
}
```

## Common Boot-Time Pitfalls

- `container.InitDefault()` panics with "redis service does not provide…" — you forgot to add the provider to `wire.Build` or to run `go generate ./container`.
- `localize.GetLocalizeFiles` returns "file does not exist" — `//go:embed *.json` only sees files in the same package directory. Ensure `localize.go` lives in `localize/`.
- `viper.WatchConfig` no-ops in containers because the file is volume-mounted read-only. That is fine; do not chase it.
- `mw.InitMw()` order matters if any mw reads `container.Default.RedisService` (e.g. rate-limit using Redis). Call `container.InitDefault()` first. Already correct in the template above.
